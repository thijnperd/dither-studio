Rebuild this page and every file on it from a clone with node tools/make-examples.js. The generator opens the real build, applies each recipe through the same calls the panels make, checks it against the app’s own catalogues, and fails rather than drawing something the app cannot make.

The paintings and their licences are recorded in SOURCES.md; README.md lists the same set as a table, and GUIDE.md explains every control named above.
