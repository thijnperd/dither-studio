# Figure sources

`build-map.mmd` and `proof-pipeline.mmd` are the Mermaid sources for
`docs/build-map.png` and `docs/proof-pipeline.png`, the figures shown in the
root `README.md` and `GUIDE.md`. The PNGs are committed so the diagrams render
the same everywhere, without depending on GitHub's Mermaid viewer.

The proof pipeline is grouped into **Prepare**, **Press** and **Finish**. The
arrows between those three groups are hand-offs between stages, not links
between individual settings.
